Operating Motion

自主迭代飞轮 (Autonomous Loop)

AI Agent 与传统单轮对话（Prompt-Response）的根本差异在于其连续执行飞轮：从环境感知（Perceive）到任务拆解（Plan），顺时针单向流动，直到目标达成。

Cognitive Core

核心决策闸门 (Decide Gate)

作为飞轮唯一的焦点节点（Focal Gate），模型在此处进行思维链推理（CoT）、工具路由与安全围栏审查，并在高危动作前请求人工对齐（Human-in-the-Loop）。

State Fabric

中枢共享记忆 (Shared Memory)

中心 Hub 是 Agent 的状态大脑。执行中的每一个阶段（尤其是工具调用的 Trace 结果与自我反思结论），均通过虚线辐条（Dashed Spokes）实时同步写回记忆池中。
